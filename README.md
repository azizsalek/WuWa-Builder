# WuWa Builder — MVP

نسخة أولية عربية ومتجاوبة لمشروع مساعد مجتمع Wuthering Waves.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفع محتويات المجلد إلى استضافة صفحات ثابتة.

## ما يعمل حالياً
- لوحة رئيسية وإحصائيات محلية.
- تسجيل Builds مع تقرير اكتمال بيانات وملاحظات عامة.
- تسجيل Echoes وخصائصها.
- إضافة شخصيات يدوياً.
- ملف لاعب محلي، تصدير JSON، وحذف البيانات.
- حفظ محلي باستخدام `localStorage`.

## غير متوفر بعد
- تسجيل دخول حقيقي أو قاعدة بيانات سحابية.
- OCR لقراءة صور Echoes.
- قاعدة بيانات موثقة ومحدثة للشخصيات والأسلحة والـ Echo Sets.
- تقييمات خاصة بكل شخصية.

## ملاحظة مهمة
مؤشر البناء الحالي يقيس اكتمال البيانات المدخلة فقط، وليس قوة البناء أو DPS. لا يتضمن المشروع Damage Calculator أو Build Optimizer.

المشروع غير رسمي وغير تابع لـ Kuro Games.
